# 风物

一阵风，吹过一个山谷的四季。

你是风。从立春到冬至，吹散晨雾、托起风筝、鼓起船帆、扬走谷糠，最后把一盏灯送上冬夜的天空。

- 在线试玩：https://claude.ai/artifact/21BP85wAPuTwr51CVLuT5d
- 本地运行：在仓库目录执行 `python3 -m http.server`，再用浏览器打开 http://localhost:8000（直接双击 `index.html` 打不开，浏览器不允许本地加载模块）
- 技术：Three.js（`three.module.js` 已随仓库附带），单文件 `index.html`，声音由 Web Audio 实时合成
- `v1/` 是最早的第一版，留作对照
